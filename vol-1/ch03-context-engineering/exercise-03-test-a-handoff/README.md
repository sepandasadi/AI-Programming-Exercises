# Exercise 3 — Test a handoff

Copy `starter/handoff.md` to a scratch file. Fill it using your Exercise 1
observations. Include the baseline, the decision and its source, the two
request results, the command to reproduce them and the next action. Keep
the command runnable from the lab checkout. Add one open question if it
could change the answer you give the caller.

Start a fresh session with the scratch note and the checkout. Ask it to
restate the question, check the governing rule and rerun the requests.

## Verification

Use the session trace to confirm it ran the command in the note. The
report should cite AC-6 and Behavior and recover the same results and
next action. Check for unsupported claims about a deployed instance.
Compare your note with [the sample handoff](solution/handoff.md).
