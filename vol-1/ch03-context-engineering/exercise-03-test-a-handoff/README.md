# Exercise 3 — Test a handoff

Copy `starter/handoff.md` to a scratch file. Fill it using your Exercise 1
observations. Include the baseline, the decision and its source, the two
request results and the next action. Add one open question if it could
change the answer you give the caller.

Start a fresh session with the scratch note and the checkout. Ask it to
restate the question, check the governing rule and rerun the requests.
Give it the location of `verify-search.mjs` if the note references it.

## Verification

You should get the same criterion, statuses and next action without
pasting the original transcript. Check for unsupported claims about a
deployed instance. Compare your note with `solution/handoff.md`.
