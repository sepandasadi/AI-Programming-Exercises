# Exercise 1 — Review a proposed change

Read the [proposed Relay change](../starter/proposed-change.md). The
request is to explain the triage decision for a selected issue. Review
what the proposed plan would give the coding or triage agent access to
and what the resulting application would do with that access.

For each numbered decision, record the asset at risk, the boundary
crossed, a control that can enforce the requirement, and evidence you
would accept in review. Include one positive check that shows the
requested task still works. Mark which changes block approval.

**Verify it.** Compare your review with the [reference review](../solution/review.md).
Each concern should have a check that can fail when the corresponding
control is missing. Highlight which checks in the reference review run
in this lab and which require an integration environment or CI.
