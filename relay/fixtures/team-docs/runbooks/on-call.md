# On-Call

## Paging

The primary on-call engineer is paged first. If there is no response
in 10 minutes, the secondary is paged.

## Incident rollback

During an incident, prefer rollback over a forward fix. See the
Rollback section of the deploying guide.

## Handover

Write a handover note every Monday: open incidents, flaky alerts and
anything the next person should watch.
